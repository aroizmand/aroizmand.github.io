WilderXanderr Analytics

WilderXanderr Analytics is a private, personal tool used by the travel creator WilderXanderr to view statistics for his own YouTube channel and Instagram account in one dashboard on his own computer.

It is not a public service: it has a single user (the channel owner), and it only reads data about his own channel. It does not post, edit or delete anything.

Data use is described in the privacy policy.
